# TC2008B - Flash Point Rescue

Simulación inspirada en Flash Point: Fire Rescue, con cavernícolas que rescatan
huevos de dinosaurio. Python/Mesa manejará las reglas y los agentes; Unity
mostrará la simulación en 3D.

## Equipo

- [vicesq17](https://github.com/vicesq17)
- [LuisFer753](https://github.com/LuisFer753)

## Estructura

- `unity/`: proyecto y visualización 3D.
- `python/`: simulación y comunicación con Unity.
- `docs/`: documentación y referencias.

Trabajar en ramas por tarea y abrir PR hacia `pre-release-0.0.1`.
`main` se reserva para versiones estables.

## Estado
